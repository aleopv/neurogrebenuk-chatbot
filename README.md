# Позвони Гребенюку — Telegram prototype

Статический кликабельный прототип Telegram-бота для сценария:

- стартовый экран;
- сбор данных;
- переход к оплате;
- экран CloudPayments;
- подтверждение подписки;
- звонок;
- PDF-отчет;
- повторный разбор.

Открывается как обычный статический сайт через `index.html` и подходит для GitHub Pages.
